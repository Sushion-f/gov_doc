# 关于做好2026年国庆节期间值班工作的通知

  • 鲁大数据中心办字〔2026〕XX号**

各部室、直属单位：

根据《国务院办公厅关于2026年部分节假日安排的通知》精神和省委省政府有关要求，为切实做好国庆节期间值班工作，现将有关事项通知如下：

## 一、放假安排

根据国务院办公厅通知，2026年国庆节放假时间为**10月1日至10月7日**，共7天。9月27日（星期日）、10月10日（星期六）正常上班。

## 二、值班要求

（一）严格执行领导带班和24小时值班制度，确保值班岗位24小时有人值守、带班领导24小时通讯畅通。

（二）值班人员要坚守岗位、履职尽责，认真做好来电来访记录和交接班工作，不得擅自离岗、脱岗。

（三）值班人员要熟悉值班业务和应急处置流程，遇有紧急重要事项按规定及时报告、妥善处置。

## 三、安全保障

（一）各部室、直属单位要在放假前开展一次全面安全检查，重点做好防火、防盗、防泄密等工作，及时消除各类安全隐患。

（二）严格执行请销假制度，节日期间因公因私外出人员需按规定提前履行报批手续。

（三）公车实行集中封存管理，确因工作需要动用公车的，须按规定报批。

## 四、报告事项

（一）实行“零报告”制度，每日16时前向值班室报告当日情况。遇有重要紧急情况，要按规定第一时间报告，严禁迟报、瞒报、漏报。

（二）紧急突发事件信息须在事件发生后30分钟内电话报告，并在1小时内形成书面材料报送。

（三）对违反值班纪律、造成不良影响的，将依规依纪严肃追究责任。
