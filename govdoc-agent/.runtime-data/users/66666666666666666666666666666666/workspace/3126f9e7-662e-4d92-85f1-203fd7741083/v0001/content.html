# 国庆放假通知（审核稿）

## 【发文稿】

  • 关于2024年国庆节放假安排的通知**

各部门、全体员工：

根据《国务院办公厅关于2024年部分节假日安排的通知》（国办发明电〔2023〕7号）精神，结合公司实际，现将2024年国庆节放假安排及有关事宜通知如下：

### 一、放假时间

2024年10月1日（星期二）至10月7日（星期一）放假调休，共**7天**。9月29日（星期日）、10月12日（星期六）上班。

### 二、有关要求

（一）请各部门于放假前完成本部门安全检查，妥善保管贵重物品，关断电源、锁好门窗，做好防火、防盗等安全防范工作。

（二）请各部门妥善安排好值班工作，于9月30日前将值班表报办公室备案。值班人员须坚守岗位，保持通讯畅通，如遇重大突发事件，按规定及时报告并妥善处置。

（三）放假期间，请全体员工注意出行安全，做好个人防护，避免前往人员密集场所。

（四）请市场部、客户服务部等相关部门提前做好客户对接工作，确保放假期间业务平稳有序。

### 三、节后提醒

10月8日（星期二）正常上班，请全体员工提前做好工作安排，确保节后各项工作顺利开展。

特此通知。

  • XX公司（盖章）**
