# 关于做好2026年国庆节期间值班工作的通知

  • 鲁大数据中心办〔2026〕XX号**

各科室、各直属单位：

根据《国务院办公厅关于2026年部分节假日安排的通知》（国办发明电〔2025〕XX号）精神，为切实做好国庆节期间值班工作，确保节日期间各项工作正常运转，现就有关事项通知如下：

## 一、放假安排

2026年国庆节放假时间为**10月1日至10月7日**，共7天。9月27日（星期日）、10月10日（星期六）正常上班。

## 二、值班要求

（一）**严格落实值班制度**。各科室、各直属单位要高度重视节日期间值班工作，切实加强组织领导，确保值班人员到岗到位。值班期间实行**24小时专人值守**，严禁出现脱岗、离岗现象。

（二）**认真履行岗位职责**。值班人员要坚守工作岗位，熟悉值班业务，认真接听来电、处理事务，做到态度热情、记录完整、处置得当。对重要紧急事项要按规定及时报告并妥善处理。

（三）**加强值班工作保障**。各科室、各直属单位要妥善安排好值班人员的工作和生活，提供必要的办公条件和生活保障，确保值班工作正常开展。

## 三、安全保障

（一）**强化安全防范意识**。各单位要在节前开展一次安全自查，重点检查办公楼宇、机房、档案室等重点部位的安全隐患，发现问题及时整改。

（二）**做好网络安全防护**。加强节日期间网络安全管理，落实网络安全责任制，做好系统运行监控和数据备份工作，确保信息系统安全稳定运行。

（三）**严格公车管理**。节日期间严格执行公车封存规定，确需使用公车的要按规定履行审批程序。

## 四、报告事项

（一）**实行零报告制度**。各科室、各直属单位每日16时前向中心总值班室报告当日情况，重要情况要立即报告。10月7日17时前报告节日期间综合情况。

（二）**畅通信息报送渠道**。遇有突发事件或重要紧急情况，值班人员要按规定第一时间向带班领导报告，并根据指示启动应急预案，妥善做好应急处置工作。

（三）**加强督促检查**。中心办公室将对各单位值班情况进行抽查检查，对脱岗离岗、敷衍塞责的单位予以通报批评。

请各科室、各直属单位接到通知后，结合实际认真贯彻落实，做好节日期间各项值班工作。
