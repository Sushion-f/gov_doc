## 一、全局通用功能

### 1.1 左侧边栏（三页通用）

| # | 功能项 | 说明 |
|---|--------|------|
| 1 | 产品名称展示 | 显示"智慧公文智能体"品牌标题 |
| 2 | 新对话 | 点击清空当前上下文，进入全新对话 |
| 3 | 云盘（工作目录） | 跳转至工作目录页（workspace.html） |
| 4 | 历史对话列表 | 展示当前用户的历史会话记录 |
| 5 | 历史对话 · 标题 | 由模型 summary 自动生成会话标题 |
| 6 | 历史对话 · 多功能菜单 | 点击`···`展开下拉菜单 |
| 6.1 | — 重命名 | 手动修改历史对话标题 |
| 6.2 | — 置顶 | 将该记录固定在历史列表顶部 |
| 6.3 | — 删除 | 删除该历史会话 |
| 7 | 侧边栏收缩按钮 | 折叠为图标轨道，释放主区域横向空间；再次点击展开 |
| 8 | 切换至旧版本 | 跳转至旧版产品入口（原型存根） |

| # | 功能项 | 说明 |

## 二、首页（homepage.html）

### 2.1 空态首屏

| # | 功能项 | 说明 |

| 1 | 欢迎语展示 | 显示"有什么我能帮你的吗"及产品说明文案 |

| 3 | 推荐问题区域 · 再次登录 | 展示个性化问题（现有 skills、基于记忆的建议任务） |

### 2.2 对话输入区（Composer）


| # | 功能项 | 说明 |
|---|--------|------|
| 1 | 文本输入框 | 多行自适应高度，支持直接输入任务目标 |
| 2 | 附件按钮`+` | 点击弹出附件下拉菜单 |
| 2.1 | — 本地上传 | 上传本地文件，同步至工作目录与云盘 |
| 2.2 | — 网盘选择 | 从个人云盘或共享资料库选择文件 |              
| 3 | 模型选择 | 点击展示模型下拉菜单，当前支持三款模型 |      
| 3.1 | — Minimax | 可选模型之一 |
| 3.2 | — Qwen 3.5 | 可选模型之一 |
| 3.3 | — DeepSeek | 可选模型之一 |
| 4 | 发送按钮 | 圆形 FAB 样式，点击发送消息触发 lead agent |
| 5 | Skill 快捷入口条 | 横向滚动的 skill 按钮条，位于输入框下方 |
| 6 | Skill 激活态 | 选中某个 skill 后输入框展示该 skill 的常用指令示例；发送时标注"发送给该 skill" |
| 7 | 上拉选项菜单（Prompt Menu） | 部分任务完成后弹出选项菜单与输入区合并显示，提供快捷选项（如全部修改 / 让我核对 / 自定义输入） |

### 2.3 Skill 快捷入口（五大能力）

| # | Skill 名称 | 图标 | 触发后输入框示例提示 |
|---|-----------|------|---------------------|
| 1 | 资料检索 | search | 例如：搜索一下关于具身智能的政策文章，并给我提炼 3 个要点。 |
| 2 | 公文写作 | edit_note | 例如：帮我写一篇关于优化营商环境的通知，语气正式，结构完整。 |
| 3 | 公文审核 | fact_check | 例如：审核这篇文章，重点看标题格式、主送单位、时间表达和错别字。 |
| 4 | 公文查重 | find_in_page | 例如：查重这篇文章，输出重复率、对应句子和来源链接。 |
| 5 | 公文排版 | auto_fix_high | 例如：排版这篇文章，优先推荐党政机关标准模板。 |

### 2.4 对话流程展示（Claw 步骤卡片）

> 所有任务均通过 lead agent 统一调度，至少展示以下步骤卡片。

| # | 功能项 | 说明 |
|---|--------|------|
| 1 | Lead Agent Thinking | 第一步卡片：lead agent 分析任务、制定计划 |
| 2 | 工具调用 · To_do_list | 生成结构化任务清单 |
| 3 | 工具调用 · search | 检索政策文件、历史材料等外部信息 |
| 4 | CLI 工具调用 · read_file | 读取用户上传或云盘中的文件内容 |
| 5 | Sub-agent 调用（Claw） | 调用对应领域专家 agent（如公文专家、审核专员、查重专员、排版专员） |
| 6 | Skills 调用 | 调用对应 skill（如 doc_format、compliance_check、similarity_match 等） |
| 7 | 步骤卡片展开/收起 | 每张步骤卡片支持点击展开详情或折叠 |
| 8 | 流式输出 | 步骤卡片按执行顺序实时流式展示 |
| 9 | 结果输出区 | 任务完成后展示最终结果（文档卡片或内联文本） |

### 2.5 消息操作（对话气泡通用）

| # | 功能项 | 说明 |
|---|--------|------|
| 1 | 复制 | 复制当前消息内容到剪贴板 |
| 2 | 点赞（大拇指向上） | 对输出结果给予正向反馈 |
| 3 | 踩（大拇指向下） | 对输出结果给予负向反馈 |      
| 4 | 刷新（重新生成） | 重新触发当前消息的生成 |

### 2.6 示例任务流程 · 公文写作

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 用户：帮我写一篇公文 | 触发 lead agent |
| 2 | lead agent → To_do_list → Claw（公文专家） → skills（doc_format, compliance_check） → search → read_file | 流式步骤展示 |
| 3 | 输出文档卡片 | 包含文件名、文种、状态、版本元信息 |
| 4 | 点击文档卡片 | 在左侧联动编辑器中打开正文，可继续编辑 |

### 2.7 示例任务流程 · 公文审核

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 用户：审核这篇文章 | 触发公文审核流程 |
| 2 | lead agent → To_do_list → Claw（审核专员） → skills（compliance_check, style_review） → read_file | 流式步骤展示 |
| 3 | 输出审核问题清单 | 显示问题数量与各项错误说明 |
| 4 | 上拉选项菜单询问用户 | 提供"全部修改 / 让我核对 / 自定义补充"三选项 |
| 4.1 | 全部修改 | 产品自动修正所有问题，输出修订版文档 |
| 4.2 | 让我核对 | 联动编辑器展开；左侧显示逐条错误列表（错误项、校正项、✔/❌）；正文中对应片段高亮 |
| 4.3 | 逐条确认/拒绝 | 每条错误可单独确认修改或拒绝，支持手动补充 |
| 5 | 完成 / 取消按钮 | 完成关闭核对模式并回写修订；取消关闭联动视图 |

### 2.8 示例任务流程 · 公文查重

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 用户：查重这篇文章 | 触发公文查重流程 |
| 2 | lead agent → To_do_list → Claw（查重专员） → skills（similarity_match, rewrite_hint） → search / compare → read_file | 流式步骤展示 |
| 3 | 输出查重结果汇总 | 总重复率、重复片段数 |
| 4 | 查重明细列表 | 每条展示：重复文章标题、重复率、重复句子、原文句子、原文链接（点击跳转） |
| 5 | 进入联动编辑器 | 左侧展示重复片段明细列表（来源标题、重复率、重复句摘要、改写建议）；正文中高亮重复片段；鼠标悬停明细联动定位正文 |
| 6 | 询问是否生成查重报告 | 上拉选项菜单：是 / 否 / 自定义 |
| 6.1 | 是 | 生成结构化查重报告文档卡片 |

### 2.9 示例任务流程 · 公文排版

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 用户：排版这篇文章 | 触发公文排版流程 |
| 2 | lead agent → To_do_list → Claw（排版专员） → skills（template_match, doc_format） → read_file | 流式步骤展示 |
| 3 | 展示推荐模板 | 默认推荐党政机关标准模板，显示模板名称与版式参数 |
| 4 | 上拉选项菜单询问用户 | 提供"推荐模板 / 手动选择模板 / 自定义输入"三选项 |
| 4.1 | 推荐模板 | 直接套用推荐模板，输出已排版文档 |
| 4.2 | 手动选择模板 | 上拉菜单展开全部模板列表供用户选择 |
| 5 | 输出排版结果文档卡片 | 包含模板名称、页边距等元信息 |

### 2.10 示例任务流程 · 资料检索

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 用户：搜索一下关于具身智能的文章 | 触发资料检索流程 |
| 2 | lead agent → To_do_list → Claw（资料检索专员） → skills（source_rank, summary_extract） → search | 流式步骤展示 |
| 3 | 输出检索结果列表 | 每条展示：文章标题、文章摘要、原文链接（点击跳转） |

### 2.11 联动编辑器（右侧滑入面板）

> 审核的人工操作审校暂时搁置
> 编辑器中的内容修改后自动更新，后期可查看该文件的修改记录

| # | 功能项 | 说明 |
|---|--------|------|
| 1 | 富文本工具栏 | 包含：正文 / 标题 / 引用段落样式；加粗；无序列表；字体/字号标注（仿宋_GB2312 三号） |
| 2 | 文档编辑区 | contenteditable 富文本区域，可直接编辑正文 |
| 3 | 问题列表侧边 | 审核/查重模式下，左侧显示逐条问题清单 |
| 4 | 正文高亮联动 | 鼠标悬停问题列表某条时，正文对应片段高亮显示 |
| 5 | 自动保存 | 修改的文字自动保存至该文件 |
| 6 | 关闭按钮 | 收起联动编辑器，主区域恢复全宽 |

## 五、智能体核心架构功能

### 5.1 Lead Agent 编排

| # | 功能项 | 说明 |
|---|--------|------|
| 1 | 统一任务入口 | 所有用户输入均经过 lead agent 路由，不绕过 agent 直接调用工具 |
| 2 | 智能规划 | lead agent 分析任务意图，生成执行计划并拆解为工具/sub-agent 调用链 |
| 3 | 上下文保持 | 同一会话上下文完整保留，支持多轮追问与衔接任务 |


### 5.2 Sub-agent

| # | Sub-agent 名称 | 适用场景 |
|---|---------------|---------|
| 1 | 公文专家 | 公文写作任务 |
| 2 | 审核专员 | 公文审核任务 |
| 3 | 查重专员 | 公文查重任务 |
| 4 | 排版专员 | 公文排版任务 |
| 5 | 资料检索专员 | 资料检索任务 |

### 5.4 Skills（原子能力）

| # | Skill 名 | 调用场景 |
|---|---------|---------|
| 1 | doc_format | 写作、排版 |
| 2 | compliance_check | 写作、审核 |
| 3 | style_review | 审核 |
| 4 | similarity_match | 查重 |
| 5 | rewrite_hint | 查重（提供改写建议） |
| 6 | template_match | 排版（匹配最适合的模板） |
| 7 | source_rank | 检索（对检索结果进行质量排序） |
| 8 | summary_extract | 检索（提炼摘要与要点） |
| 9 | writing-search | 写作辅助检索 |
| 10 | writing-review | 写作辅助审核 |
